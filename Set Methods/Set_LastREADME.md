# Set Methods: discard(), pop(), and clear()

## Introduction
These methods help you manage elements inside a set — whether it’s removing one safely, popping randomly, or clearing everything at once.

## 1. discard(item)
- Removes the item if it exists.
- Doesn’t raise an error if the item isn’t found.
- Like removing a name from a guest list—quiet and safe.

## 2. pop()
- Removes and returns a random element from the set.
- You don’t choose which one goes—it just picks and removes.
- Like drawing a name from a hat.

## 3. clear()
- Empties the whole set.
- Think of it like resetting your to-do list or emptying your cart.
