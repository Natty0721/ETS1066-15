# Set Methods: `symmetric_difference()`, `issubset()`, and `issuperset()`

## Introduction
These three methods help you compare sets deeply — who is different, who is included, and who contains who.

## 1. `symmetric_difference(set)`
- Returns elements that are in either set, but not both.
- Like comparing two friend circles and finding who’s NOT mutual.
- Good for highlighting exclusive items.

## 2. `issubset(set)`
- Returns `True` if all elements of the current set are in another.
- Like checking if a club’s members are also registered students.
- Great for permission systems and validation checks.

## 3. `issuperset(set)`
- Opposite of `issubset()`.
- Checks if the current set includes all elements of another.
- Like asking: “Do I have everything needed to complete this task?”
