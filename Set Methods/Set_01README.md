# Set Methods: add(), update(), and remove()

# Introduction
Sets are unordered collections of unique elements. They’re great for membership tests, removing duplicates, and storing distinct values.

## 1. add(item)
- Adds a single element to a set.
- Like adding one person to a guest list.
- Does nothing if the item already exists.

## 2. update(iterable)
- Adds multiple elements to a set.
- Like importing several new contacts into your phone at once.
- Can take lists, tuples, or other sets as input.

## 3. remove(item)
- Removes a specific item from a set.
- Like removing a finished task from a to-do list.
- Raises an error if the item doesn't exist.
