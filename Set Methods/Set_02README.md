# Set Methods: union(), intersection(), and difference()

These methods are all about comparing sets like comparing groups of people, lists of items, or anything with overlaps and differences.


## 1. union()
- Combines all unique items from two sets.
- Like combining two friend groups without repeating anyone.
- Good for gathering everything in one place.


## 2. intersection()
- Returns only the common elements between two sets.
- Like finding people who belong to both clubs.
- Perfect for overlap checking or shared interest detection.


## 3. difference()
- Returns elements found only in the first set.
- Like figuring out which courses you took that someone else didn’t.
- Useful for finding unique entries or exclusions.
