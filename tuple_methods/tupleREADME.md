# Tuple Concepts: count(), and index()

# Introduction
Tuples are ordered, immutable collections. They’re like locked containers—you can access and read them, but not change them. Useful for storing fixed groups of data like coordinates, dates, or records.

## 1. count(value)
- Returns how many times a value appears in the tuple.
- Like checking how many times a student scored 90.
- Useful for counting repeated entries.

## 2. index(value)
- Returns the first position of a value in the tuple.
- Like asking: “Where did the first ‘Absent’ occur?”
- Helps find the position of a value without looping manually.
