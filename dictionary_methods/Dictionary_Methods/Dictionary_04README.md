# My today's dictionary Methods: items(), pop(), and update()
These methods helps us access key-value pairs, remove entries, and add/update information inside your dictionary.

## 1. items()
- Returns all key-value pairs in the dictionary.
- Like listing every entry in a contact list.
- Useful for looping through or displaying full dictionary content.

## 2. pop(key)
- Removes the item with the specified key.
- Think of it like checking off and deleting a task from a list.
- Helps clean up entries without deleting the whole dictionary.

## 3. update(dict)
- Adds new items or updates existing ones.
- Like editing or expanding a form.
- Handy for merging settings, adding new data, or modifying values.
