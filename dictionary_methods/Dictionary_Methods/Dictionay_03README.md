# Dictionary Methods: clear(), copy(), and fromkeys()

These methods help in resetting, duplicating, and creating dictionaries efficiently. They’re especially useful in real-world programs where reuse, data reset, or initialization is required.

## 1. clear()
- Empties the entire dictionary.
- Like wiping a whiteboard clean—all data gone, but the board remains!
- Handy when you want to reuse the same variable.

## 2. copy()
- Creates a duplicate of the dictionary.
- Think of it as making a photocopy—you keep the original safe.
- Good for backups or templates.

## 3. fromkeys()
- Creates a dictionary from a list of keys, all having the same value.
- Like making a checklist with default values (e.g., all unchecked).
- Great for bulk initialization (attendance, scores, settings, etc.).
